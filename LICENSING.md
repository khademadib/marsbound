# Licensing and copyright status

## Recommendation: Apache License 2.0 for original project work

MarsBound was created for the **2026 NASA Space Apps Challenge**. The [2026 NASA Space Apps Participant Terms and Conditions](https://www.spaceappschallenge.org/legal/) state that original content in posted solutions must be freely available without restriction or licensed as open source under an OSI-compliant license. The terms also state that, if a participant does not specify a particular OSI-compliant license, NASA will distribute the original content under the **Apache License 2.0**.

For consistency with that stated default, **Apache-2.0 is the recommended license for the team's original code and original project assets**, provided the relevant contributors have the rights and have agreed to authorize that license.

## What this means

Apache 2.0 is an open-source license. It permits people to use, copy, modify, and redistribute the licensed work, including commercially, subject to its conditions. It includes an express patent license and requires preservation of applicable notices and the license. It does **not** prevent copying or guarantee that nobody will reuse the game.

MIT is also a permissive open-source license and allows broad reuse. Neither MIT nor Apache 2.0 is a "no copying" license. An all-rights-reserved approach would conflict with the open-source requirement for a posted NASA Space Apps solution.

## Contributor confirmation required

Before adding a repository-wide license file, the team should confirm that:

1. Each person who created original code, writing, gameplay design, art, or other material has agreed that their contribution may be released under Apache 2.0, or the team otherwise has written authority to license it.
2. The team has the rights needed to grant the rights described in the license for every contribution covered by it.
3. Any reused third-party work is compatible with the NASA terms and its own license/usage terms are documented.
4. The final NASA project submission names the license consistently with the repository.

This is especially important for the game implementation supplied by a teammate. Repository ownership or the act of uploading someone else's code does not automatically give the repository owner authority to relicense that contribution.

## Third-party material is separate

The project-wide license applies only to original work the contributors are authorized to license. It does not override the separate license for the **Press Start 2P** font (SIL Open Font License 1.1), nor does it relicense NASA/JPL images. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and [SOURCES.md](SOURCES.md).

NASA's [Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) generally allow NASA media to be used for factual educational/informational purposes under the stated conditions, with NASA acknowledged and no implied endorsement. Third-party copyrighted material hosted on NASA pages still requires the rights holder's permission or applicable license; check individual image pages.

## Current repository status

**The repository does not yet contain a project-wide `LICENSE` file.** This document records the recommended decision and the checks still needed; it is not itself a software license. Once the contributors approve Apache 2.0 and confirm licensing authority, add the complete, unmodified Apache License 2.0 text as `LICENSE`, with a copyright notice approved by the rights holders.
