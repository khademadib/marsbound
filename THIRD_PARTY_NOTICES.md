# Third-party notices

## Press Start 2P

The current game loads the **Press Start 2P** display font through the Google Fonts stylesheet:

- [Google Fonts specimen](https://fonts.google.com/specimen/Press+Start+2P)
- [Official font license file in Google Fonts repository](https://raw.githubusercontent.com/google/fonts/main/ofl/pressstart2p/OFL.txt)

The font's notice identifies:

> Copyright 2012 The Press Start 2P Project Authors (cody@zone38.net), with Reserved Font Name "Press Start 2P".

Press Start 2P is licensed under the **SIL Open Font License, Version 1.1 (OFL-1.1)**. The font remains under its own license and is not relicensed under the MarsBound project license. The current repository loads the font from Google Fonts and does not contain a bundled font binary. If the font files are later copied into this repository or distributed with a release, include the required OFL notice and license with them.

## Other assets

The reviewed baseline contains no external image files, audio files, or third-party JavaScript libraries. The game's pixel-art scene is drawn in Canvas, and its sound and music are generated in the browser with the Web Audio API. The `favicon.svg` is a project-created MarsBound icon.

This notice must be updated if the final game adds stock images, audio, datasets, libraries, fonts, templates, or other third-party material. Record each item's creator/source and exact license, and make sure the team has permission to include it.
